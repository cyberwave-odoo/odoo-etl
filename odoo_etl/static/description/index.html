Odoo ETL Solution

This module provides an ETL (Extract, Transform, Load) solution for Odoo, enabling seamless data import, transformation, and synchronization between external databases and Odoo models. It is designed to handle complex data mappings and transformations efficiently.

Features

  • Define and manage ETL processes for various Odoo models.
  • Efficient data manipulation and transformation using Polars.
  • Support for SQLite and other external databases.
  • Customizable import logic for specific use cases.
  • Batch processing for large datasets.

Getting Started

Follow these steps to set up and use the ETL module:

  1. Install the Odoo module and its dependencies.
  2. Define ETL models in Odoo, specifying field mappings and transformation logic.
  3. Trigger the import process to synchronize data between external databases and Odoo.

Example Field Mapping

Here is an example of how fields can be mapped between an external table and an Odoo model:

{
  "name": {"type": "column", "column_name": "external_name"},
  "email": {"type": "lambda", "function": lambda self, row, **kwargs: row["email"].lower()},
  "country_id": {
    "type": "join",
    "lookup_table": "res.country",
    "left_on": "country_code",
    "right_on": "code",
    "model_field": "id"
  }
}

Pro Tips

  • Follow legal regulations when handling sensitive data, such as personal identifiers.
